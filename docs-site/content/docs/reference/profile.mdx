## `wallapop profile`

Manage named accounts

## `wallapop profile list`

List profiles with a session

```bash
wallapop profile list
```

## `wallapop profile remove`

Delete a profile's session, config and watches

```bash
wallapop profile remove NAME [flags]
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--yes` | bool | `false` | do not prompt |

## `wallapop profile use`

Make a profile the default

```bash
wallapop profile use NAME
```

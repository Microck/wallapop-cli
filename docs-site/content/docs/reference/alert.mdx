## `wallapop alert`

Wallapop's saved searches (server-side alerts), read-only

## `wallapop alert list`

List the account's saved searches

```bash
wallapop alert list
```

List the saved searches Wallapop keeps for the account, with the query each
one runs. Turn one into a local watch with:

  wallapop watch add search --from-alert ID --name NAME

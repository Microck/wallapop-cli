<Callout type="info" title="Version 0.1.0">
  Every path below was verified against the v0.1.0 release and prints `wallapop 0.1.0`.
  Each release also ships `checksums.txt` with a GitHub provenance attestation.
</Callout>

## Installer

Installs the latest release into `~/.local/bin` (override with `WALLAPOP_INSTALL_DIR`):

```bash
curl -fsSL https://raw.githubusercontent.com/Microck/wallapop-cli/main/scripts/install.sh | sh
```

## Homebrew

```bash
brew install Microck/tap/wallapop
wallapop --version
```

## Scoop

```powershell
scoop bucket add microck https://github.com/Microck/scoop-bucket
scoop install microck/wallapop
wallapop --version
```

## npm

```bash
npm install -g wallapop-cli
wallapop --version
```

The postinstall step downloads the matching release archive for your platform, checks its
SHA-256 against `checksums.txt`, and installs the binary.

## Arch Linux

```bash
yay -S wallapop-cli-bin
wallapop --version
```

The installer picks the right archive for your platform (Linux amd64 and arm64 are covered),
verifies the checksum and installs the binary.

## Go install

```bash
go install github.com/Microck/wallapop-cli/cmd/wallapop@v0.1.0
wallapop --version
```


## Check it works

```bash
wallapop --version
wallapop doctor
```

`doctor` checks that the config parses, the session mints, Wallapop is reachable and the chat
token can be fetched. Run it first whenever something behaves oddly.

## From source

Install the current source with Go:

```bash
go install github.com/Microck/wallapop-cli/cmd/wallapop@latest
wallapop --version
```


## Check it works

```bash
wallapop --version
wallapop doctor
```

`doctor` checks that the config parses, the session mints, Wallapop is reachable and the chat
token can be fetched. Run it first whenever something behaves oddly.
